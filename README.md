# ANYSOCIAL Homebrew Tap

Official Homebrew tap for [Battery Autopilot](https://macbattery.net/) — AI that runs your Mac's battery on autopilot.

## Install

```sh
brew install --cask anysocial-g/tap/battery-autopilot
```

Requires Apple Silicon (M1 or later) and macOS 15+.

## Upgrade

The app updates itself (Sparkle). You can also run:

```sh
brew upgrade --cask battery-autopilot
```
